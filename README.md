## 🎯 Repository Purpose
The goal of this repo is to explore different programming languages and explore options
* **Visual Logic (Scratch):** Prototyping algorithms and game logic using block-based programming.
* **Procedural Programming (C):** Mastering the "Bare Metal" logic, pointers, and manual memory management.
* **Object-Oriented Programming (C++):** Learning classes, inheritance, and the Standard Template Library (STL).
